# micro_gateway
base on spring cloud gateway

一个用来演示和练习的网关demo


## 预期规划的API网关的功能

### JWT 增强配置

```js
白名单 → JWT格式检查 → 基础解析(kid,jti,exp) → 过期检查 →
租户识别 → 签名验证 → 黑名单检查 → 上下文设置
```


| 配置项           | 是否完成 | 说明                             |
|------------------|----------|----------------------------------|
| `multi-tenant`   | [ ]      | 识别多租户上下文                 |
| `blacklist`      | [ ]      | 令牌黑名单，检查令牌是否被撤销   |
| `auth`           | [ ]      | 基础 JWT 签名和过期验证          |
| `refresh-token`  | [ ]      | 刷新令牌机制                     |
| `OAuth2.0 集成`          | [ ]      |            |
| `API Key 认证`          | [ ]      |            |
| `SSO 单点登录`          | [ ]      |            |
| `基础认证（内部服务间）`          | [ ]      |            |
